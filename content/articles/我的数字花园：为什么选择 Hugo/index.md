这个博客叫「打哈欠的树」，是我的个人数字花园。它用来长期记录学习、研究、生活和思想——不追求流量，只为了保存那些认真想过的、值得留下的东西。

## 为什么是静态站点

个人博客的核心需求只有三个：

1. **内容属于自己**：所有文字都以 Markdown 存在本地，用 Git 管理版本；
2. **零维护成本**：不买服务器、不续费、不担心被攻击；
3. **加载足够快**：静态页面几乎不需要等待。

静态站点生成器正好满足这些。对比了几个方案之后，我选择了 Hugo。

### 选择 Hugo 的理由

- 用 Go 编写，构建速度极快，内容再多也不怕；
- 单文件二进制，安装简单；
- 原生支持目录（TOC）、代码高亮、RSS；
- 主题就是普通的 HTML/CSS，容易完全掌控风格。

## 目录结构

内容按类型分目录存放，写作时只需要新建 Markdown 文件：

```text
content/
├── articles/    # 文章：技术、学习、项目、思考
├── notes/       # 随记：短文本、日常、灵感
└── about/       # 关于页
```

## 写作与发布

写作流程很简单：新建 Markdown 文件 → 本地预览 → `git push`。GitHub Actions 会自动构建并发布到 GitHub Pages，全程免费。

```bash
hugo new articles/我的新文章/index.md   # 新建一篇草稿
hugo server                            # 本地预览
git add . && git commit -m "写点什么"   # 记录版本
git push origin main                   # 触发自动发布
```

## 最后

数字花园不是一次性建成的。它更像一棵树：慢慢长，不断添新的枝桠。这个博客也会如此。
